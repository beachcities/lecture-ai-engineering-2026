- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：gemini-3.5-flash-lite は講座名を「おそらく AIエンジニア育成プログラム2026」などと推測し、一般的な3段階（ビギナー／スタンダード／チャレンジ）を答えた。最後に、教材やコミュニティで確認するよう促していた。
- 用語集の正しい意味と比べて気づいたこと：用語集（data/glossary.json の homework-levels）では、3レベルは「基礎（講義内容の確認）」「実装（自分でコードを書く）」「発展（調査や試行）」で、どれか1つに取り組めば完了、原則として採点はしない。モデルは「3段階の難易度」という形は合っていたが、講座名を推測で補い、「どれか1つで完了」「採点しない」には触れなかった。
- 表示できたトークン数（入力 / 出力）：「LoRA とは何ですか？」で入力 7 / 出力 576（gemini-3.5-flash-lite）。改修は GitHub Copilot のチャット（Agent、モデル選択 Auto、表示は GPT-5.6 Luna）に依頼し、差分を読んでから採用した。

## 宿題

- 取り組んだレベル：基礎
- やったこと：同じ質問「AIE2026 の講座の宿題にある「3レベル」とは何ですか？」を、AIE_MODEL で gemini-3.5-flash-lite と gemini-3.8-flash に切り替えて3回ずつ実行した。出力は lectures/01/runs_basic.txt に保存した。temperature は変えていない。
- 結果：
  - gemini-3.5-flash-lite：3回とも成功。入力 21 トークン、出力 551 / 537 / 717 トークン。3回とも講座名を推測し、一般論の3段階を答えた。3回目は Aidemy などの実在の事業者名を挙げ、「スキル到達度の3層」という別の解釈も加えていた。
  - gemini-3.8-flash：1回目は 503（混雑）で失敗し、2・3回目は成功。出力 639 / 640 トークン。講座名は推測せず、「課題の達成度」と「AI活用の深度」の2パターンを並べ、課題文と照らして確認するよう促した。
  - 6回のうち、用語集の要点（基礎・実装・発展の名称、どれか1つで完了、原則採点しない）を答えた回はなかった。
- 気づき・疑問：
  - 同じモデル・同じ質問でも、出力の長さや挙げる例、解釈の数が回ごとに変わった。gemini-3.8-flash の2回は出力トークン数がほぼ同じだったが、成功が2回だけなので、揺れが小さいとまでは言えない。
  - 上位モデルは推測で埋めず、条件付きで答える書き方になった。ただし、講座固有の事実を知らない点はどちらのモデルも同じだった。
  - 表示しているのは prompt_token_count と candidates_token_count だけで、思考トークン（thoughts_token_count）が使われているかは確かめていない。上位モデルの応答時間やコストを比べるなら、ここも見る必要がありそう。
